Report a problem

For when Harrier is too broken to report it itself

If Harrier still starts, report it from inside the app instead — the gear icon in the dashboard header, then Report a problem. That version attaches your version, preflight results and recent logs automatically, so it is far more useful than anything you can type here. This page is the fallback for when the app will not start at all.

Tell us what happened

Nothing is sent from this page. It writes the report for you; you send it from your own email. Fill in whatever you know — every field except the first is optional.

What you were doing, and what happened instead. If there is an error message, paste it in — it is usually the single most useful thing in a report.

Leave blank if you would rather not hear back.

From harrier --help or your purchase email. "Don't know" is fine.

Filled in from your browser. Correct it if you are writing this from a different machine.

This page collects nothing. There is no server behind it and no analytics on it. What you type stays in this browser tab until you press one of the buttons below, and both of those hand the text to you — one opens your email app with it, the other copies it to your clipboard. Please do not paste API keys or passwords: unlike the in-app reporter, this page cannot scrub them for you.
